4. Comandos para iniciar el proceso de instalación Docker 
 
- Actualizar Ubuntu 
sudo apt update && sudo apt upgrade -y 
 
- Instalar capa gráﬁca (OPCIONAL, no recomendada porque aumentaría el consumo de 
disco) 
sudo apt install xubuntu-desktop -y 
 
- Instalar Docker en ubuntu (instalación de dependencias) 
sudo apt install ca-cer�ﬁcates curl gnupg lsb-release -y 
 
- Clave GPG oﬁcial de Docker: 
sudo mkdir -p /etc/apt/keyrings 
curl -fsSL htps://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o 
/etc/apt/keyrings/docker.gpg 
 
- Repositorio Docker: 
echo \ 
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \ 
  htps://download.docker.com/linux/ubuntu \ 
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null 
 
- Instalar Docker Engine, cli y contenedores 
sudo apt update 
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-
compose-plugin -y 
 
- Veriﬁcando estado de Docker

5. Uso de Docker con emqx y mysql 
 
- Creamos una carpeta: 
mkdir emqx_mysql_stack 
cd emqx_mysql_stack 
 
- Creamos el código: 
nano docker-compose.yml 
 
- El contenido del código es: 
version: "3.9" 
 
services: 
  emqx: 
    image: emqx/emqx:latest 
    container_name: emqx 
    restart: always 
    ports: 
      - "1883:1883" 
      - "8083:8083" 
      - "8084:8084" 
      - "18083:18083"
